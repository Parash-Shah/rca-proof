Incident & evidence API

RCAProof

Investigate incidents through controlled experiments. Preserve the evidence, test the suspected causes, and retrieve a bounded causal proof.

This is the API landing page. Incident creation, evidence intake, and investigations currently use HTTP requests or the demo script; an interactive dashboard is not implemented yet.

Run the three decision outcomes

From the project directory, investigate a duplicate payment, expected access denial, and an inconclusive timeout. Review a remediation plan or the reason no change is proposed:

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/demo-classification.ps1

The script prints the incident ID and saves the proof under artifacts/. Use that ID in the endpoints below.

Verify the implemented payment candidate against replay, nearby faults, concurrent deliveries and bounded load:

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/demo-verification.ps1

The 22 checks cover replay, expiry, durable reconciliation, migration and rollback. Certification also requires an exact committed build and trusted signed CI evidence. Development builds remain uncertified.

Reproduce an HTTP retry storm against the local WireMock dependency and verify a bounded-retry policy:

powershell -NoProfile -ExecutionPolicy Bypass -File scripts/demo-http-retry.ps1

This 16-check suite measures dependency-side request counts, transient recovery, concurrent budgets, latency, caller deadlines and broken connections. Certification requires the matching signed HTTP retry contract and committed build.
